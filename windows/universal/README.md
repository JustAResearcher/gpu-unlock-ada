# Универсальный Multi-GPU порт разблокировки для Windows — Ampere & Ada Lovelace

Автономный UEFI-загрузчик для одновременной энергозависимой разблокировки видеокарт NVIDIA архитектур **Ada Lovelace (RTX 40xx)** и **Ampere (RTX 30xx)** под управлением **Windows 10/11 x64 (NVIDIA Drivers)**.

Проект базируется на наработках [JustAResearcher/gpu-unlock-ada](https://github.com/JustAResearcher/gpu-unlock-ada) и [impacifist/Windows-GPU-UNLOCK](https://github.com/impacifist/Windows-GPU-UNLOCK). Загрузчик отрабатывает в фазе UEFI до инициализации видеодрайвера Windows и позволяет запускать видеокарты без ошибки «Код 43» с полным доступом к тензорным ядрам на максимальной кремниевой скорости.

100% Volatile In-RAM — загрузчик **никогда не прошивает физическую микросхему SPI Flash**. Все модификации происходят исключительно в оперативной памяти хоста и MMIO BAR0. При перезагрузке без флешки видеокарты остаются в 100% заводском стоковом состоянии.

## Сравнение производительности: Сток vs UEFI-Анлок (cuBLAS GEMM)

Тестирование проводилось на физическом оборудовании в среде Windows 11 x64 с официальным драйвером NVIDIA 616.92 при помощи PyTorch cuBLAS:

| Тест (cuBLAS GEMM) | СТОК (без анлока) | С НАШИМ UEFI-АНЛОКОМ | Разница / Прирост | Энергопотребление |
|---|---:|---:|:---:|:---:|
| **BF16 Tensor Cores** | **73.19 TFLOP/s** | **143.76 TFLOP/s** | **+96.4% (в 2 РАЗА БЫСТРЕЕ!)** 🔥 | **284.9 Вт** (TDP 100%) |
| **FP16 Tensor Cores** | **73.58 TFLOP/s** | **140.10 TFLOP/s** | **+90.4% прирост** | **278.0 Вт** |
| **FP32 CUDA Cores** | **26.82 TFLOP/s** | **27.29 TFLOP/s** | **Паритет** (CUDA-ядра не режутся) | **283.9 Вт** |

> [!NOTE]
> **Физика процесса и энергопотребление**:
> - В тесте **FP32 (CUDA-ядра)** видеокарта и в стоке, и с анлоком упирается в максимальный аппаратный лимит платы (**~284 Вт**) и выдаёт одинаковые паспортные **~27–28 TFLOP/s**, так как стандартные векторные шейдеры NVIDIA не лочит.
> - На **тензорных ядрах (FP16/BF16)** в стоковом режиме драйвер искусственно сдерживает скорость планировщика: видеокарта намертво упирается в потолок **80.6–80.8 TFLOPS** даже при разгоне ядра до 2775 МГц.
> - Наш UEFI-загрузчик снимает эту блокировку прошивки: тензорные ядра выходят на полную кремниевую скорость **142+ TFLOP/s** при потреблении **276–284 Вт**, полностью насыщая аппаратный лимит питания платы.

## Особенности связки и параметры железа

- **Физически протестированный стенд**:
  - **Материнская плата**: Huananzhi X99-F8D Plus (Dual LGA2011-3, чипсет Intel C612 / X99, UEFI AMI Aptio V).
  - **Процессоры**: 2 × Intel Xeon E5-2696 v3 (Haswell-EP, 36 ядер / 72 потока).
  - **Видеокарта**: Gigabyte GeForce RTX 4070 Ti WINDFORCE OC (AD104-400, PCI ID `10de:2782`, Subsystem `1458:40e8`, ревизия A1).
- **Строгая адресация VBIOS по Hardware ID**:
  - Файлы именуются по аппаратному PCI Subsystem ID: `\EFI\VBIOS\<VENDOR>_<DEVICE>_<SUBVENDOR>_<SUBDEVICE>.rom` (например, `10de_2782_1458_40e8.rom`). Никаких захардкоженных имен.
  - Если в системе установлено несколько одинаковых карт, образ VBIOS загружается в RAM один раз и применяется ко всем.
- **Поддержка поколений**:
  - **Ada Lovelace**: AD102, AD103, AD104, AD106, AD107 (RTX 4060 — 4090).
  - **Ampere**: GA102, GA103, GA104, GA106, GA107 (RTX 3050 — 3090).
- **Селекторы подсистемы**: На входе `SS0=0x41145131` / `0x60145131`, `SS1=0x4` $\rightarrow$ Фиксация защёлки: `SS0=0x88888888`, `SS1=0x8`.
- **Драйвер**: NVIDIA (загрузка чистая, диспетчер устройств рапортует «Устройство работает нормально»).

## Архитектура универсального загрузчика

1. **Независимость от материнских плат и ACPI**:
   - Автоматический динамический поиск `bootmgfw.efi` по всем разделам ESP/FAT без захардкоженных GUID дисков.
   - Корректное высвобождение GOP через `DisconnectController()` с синхронизацией регистров PCI Command (IO + Memory Space decode enabled, Bus Master disabled перед claim-транзакцией).
2. **Multi-GPU и разделение ролей**:
   - Сканирование всей топологии PCIe по всем сегментам, мостам и сокетам (Dual Xeon / EPYC / Threadripper).
   - Поддержка связок карт одного или разных поколений (например, RTX 4070 Ti + RTX 3060).
   - Корректная обработка адаптера вывода изображения (Display Adapter с активным GOP) и чистых вычислительных карт (Headless Compute).
3. **Прямое постраничное выделение памяти**:
   - Большие прошивки микрокода (`gsp_ga10x.bin`, 84.3 МБ) загружаются через прямое постраничное выделение физической памяти (`gBS->AllocatePages`), предотвращая сбои из-за фрагментации пула UEFI.

## Сборка бинарника

Для сборки используется автономный кросс-компилятор w64devkit (GCC 16.2.0):

```powershell
python build.py
```

Скрипт компилирует все модули C с оптимизацией `-O2`, собирает исполняемый файл и автоматически обнуляет таблицу импорта PE для исключения динамических зависимостей в среде UEFI ImageLoader.

Результат сборки: `dist/EFI/BOOT/BOOTX64.EFI` (~116 КБ, чистый PE32+).

## Подготовка флешки и запуск

1. Отформатируйте USB-флешку в файловую систему **FAT32**.
2. Скопируйте файлы согласно структуре:
```text
USB_ROOT/
├── EFI/
│   ├── BOOT/
│   │   └── BOOTX64.EFI              <-- Скомпилированный загрузчик
│   ├── ASSETS/
│   │   ├── booter_load_ad102.bin    (57 672 байт)
│   │   ├── booter_load_ga102.bin    (61 256 байт)
│   │   ├── gsp_boot_ad102.bin       (36 864 байт)
│   │   ├── gsp_boot_desc_ad102.bin  (84 байт)
│   │   ├── gsp_boot_desc_ga102.bin  (84 байт)
│   │   ├── gsp_boot_ga102.bin       (24 576 байт)
│   │   ├── gsp_ga10x.bin            (84 277 400 байт)
│   │   ├── v67-ad102-610.43.03-four-plm.bin (64 000 байт)
│   │   ├── v67-ga102-610.43.03.bin  (64 000 байт)
│   │   └── NVIDIA-LICENSE
│   └── VBIOS/
│       └── 10de_2782_1458_40e8.rom  <-- Дамп вашей видеокарты
├── copy_to_usb.bat                  <-- Быстрое копирование в 1 клик
├── dump_vbios.bat                   <-- Снятие дампа VBIOS в Windows
└── nvflashk.exe
```

*(Или просто запустите `copy_to_usb.bat`, введите букву вашей флешки, и скрипт развернёт всё автоматически).*

### Запуск системы:

> [!IMPORTANT]
> **Требуется физический «холодный старт» (Cold Boot)!**  
> Не используйте вход в меню `Boot Override` из настроек BIOS — в этом случае видеокарта уже будет инициализирована прошивкой материнской платы, а защитные проверки загрузчика отклонят транзакцию.

**Рекомендуемый порядок запуска:**
1. Отключите **Secure Boot** в настройках BIOS.
2. Во вкладке **`Boot`** выставьте вашу USB-флешку на **1-е место (Boot Option #1)** и сохраните настройки (`F10`).
3. **Выключите ПК (Завершение работы)** — достаточно обычного выключения (обесточивать блок питания или выдергивать шнур из розетки не нужно).
4. Включите ПК кнопкой питания — материнская плата сама запустит загрузчик с флешки на холодную.
5. Появится текстовое меню загрузчика. Нажмите клавишу **`U`** (один раз) для применения разблокировки.  
   *(По умолчанию через 30 секунд автоматически применяется разблокировка [U]; клавиша `S` загружает обычную Windows без изменений состояния GPU).*
6. Картинка застынет на 2-3 секунды (происходит освобождение GOP, инжекция микрокодов и передача управления `bootmgfw.efi`), после чего начнётся стандартная загрузка Windows 11.
7. Лог выполнения транзакции сохранится на флешке в папке `UNLOCK-LOGS/RUNxxxx.TXT`.

## Утилиты и скрипты

* **`dump_vbios.bat`** / **`dump_vbios.ps1`** — автоматическое определение установленных видеокарт и создание дампов VBIOS с именами по PCI Subsystem ID.
* **`copy_to_usb.bat`** / **`copy_to_usb.ps1`** — автоматическое развертывание загрузчика, ассетов и VBIOS на FAT32-флешку.
* **`build.py`** — сборка EFI-бинарника с очисткой таблицы импорта.
* **`tools/package_usb.py`** — скрипт упаковки файлов дистрибутива.
